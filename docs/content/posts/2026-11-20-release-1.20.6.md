The Apache Flink Community is pleased to announce the sixth bug fix release of the Flink 1.20 series.

This release fixes 46 issues in Flink 1.20, including a log4j upgrade for CVE-2025-68161 ([FLINK-39146](https://issues.apache.org/jira/browse/FLINK-39146)), redaction of sensitive configuration values in SQL Gateway responses ([FLINK-40539](https://issues.apache.org/jira/browse/FLINK-40539)), watermark fixes for inputs that become active again after idleness ([FLINK-40475](https://issues.apache.org/jira/browse/FLINK-40475)), correct CAST results for timestamps before 1970 ([FLINK-41280](https://issues.apache.org/jira/browse/FLINK-41280)), and a fix for batch sorts that could emit unsorted rows ([FLINK-40959](https://issues.apache.org/jira/browse/FLINK-40959)). The list below excludes test-only, CI and build, documentation-only, and release-tooling changes; for a complete list of all changes see [JIRA](https://issues.apache.org/jira/secure/ReleaseNote.jspa?version=12357158&projectId=12315522).

We highly recommend all users upgrade to Flink 1.20.6.

The Apache Flink Community is pleased to announce the third bug fix release of the Flink 2.1 series.

This release includes 5 bug fixes, vulnerability fixes, and minor improvements for Flink 2.1.
Below you will find a list of all bug fixes and improvements (excluding improvements to the build infrastructure and build stability). For a complete list of all changes see:
[JIRA](https://issues.apache.org/jira/secure/ReleaseNote.jspa?projectId=12315522&version=12356862).

We highly recommend all users upgrade to Flink 2.1.3 or higher.

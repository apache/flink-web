The Apache Flink Community is pleased to announce the second bug fix release of the Flink 2.2 series.

This release includes 75 bug fixes, vulnerability fixes, and minor improvements for Flink 2.2.
Below you will find a list of all bug fixes and improvements (excluding improvements to the build infrastructure and build stability). For a complete list of all changes see:
[JIRA](https://issues.apache.org/jira/secure/ReleaseNote.jspa?projectId=12315522&version=12357057).

We highly recommend all users upgrade to Flink 2.2.2 or higher.

The Apache Flink Community is pleased to announce the second bug fix release of the Flink 2.2 series.

This release fixes 74 issues in Flink 2.2, including a log4j upgrade for CVE-2025-68161 ([FLINK-39146](https://issues.apache.org/jira/browse/FLINK-39146)), redaction of sensitive configuration values in SQL Gateway responses ([FLINK-40539](https://issues.apache.org/jira/browse/FLINK-40539)), a fix for unrestorable checkpoints after a CLAIM-mode restore from a native savepoint ([FLINK-39964](https://issues.apache.org/jira/browse/FLINK-39964)), correct outer join results when an input record is updated without UPDATE_BEFORE ([FLINK-40809](https://issues.apache.org/jira/browse/FLINK-40809)), and watermark fixes for inputs that become active again after idleness ([FLINK-40475](https://issues.apache.org/jira/browse/FLINK-40475)). The list below excludes test-only, CI and build, documentation-only, and release-tooling changes; for a complete list of all changes see [JIRA](https://issues.apache.org/jira/secure/ReleaseNote.jspa?version=12357057&projectId=12315522).

We highly recommend all users upgrade to Flink 2.2.2.
